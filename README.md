# Password Manager

Gestor de contraseñas desarrollado en Python como proyecto de aprendizaje de programación, seguridad básica y buenas prácticas de desarrollo con Git y GitHub.

## Objetivo

Crear una aplicación que permita generar contraseñas seguras y, en futuras versiones, almacenarlas de forma cifrada.

## Funcionalidades previstas

- Generar contraseñas aleatorias.
- Configurar la longitud de las contraseñas.
- Elegir entre mayúsculas, minúsculas, números y símbolos.
- Copiar contraseñas al portapapeles.
- Incorporar almacenamiento cifrado en futuras versiones.

## Tecnologías

- Python
- Git
- GitHub
- pytest para las pruebas automatizadas

## Estado del proyecto

En desarrollo.



## Seguridad

El proyecto tiene fines educativos. No se recomienda almacenar contraseñas reales hasta implementar y verificar las medidas de seguridad necesarias.
## Flujo de trabajo

El desarrollo se organiza mediante ramas de Git, commits convencionales, Issues y Pull Requests en GitHub.

Las nuevas funcionalidades se desarrollan en ramas independientes y se integran en `develop` después de revisar los cambios.
